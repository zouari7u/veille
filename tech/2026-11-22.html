Thinking Machines lance Inkling 2 Mini, un modèle ouvert à transformateur bouclé

Ce modèle de 26,4 milliards de paramètres utilise une architecture bouclée pour raisonner en interne avec un nombre réduit de jetons.

Repères

  • Paramètres totaux : 26,4 milliards
  • Paramètres actifs par jeton : 5,4 milliards
  • Licence : Apache 2.0
  • Score DeepSWE v1.1 : 48,2 %
  • Score Vals Index v2.2 : 46,5 %

Thinking Machines a publié Inkling 2 Mini, un transformateur bouclé où 12 des 24 couches s'exécutent trois fois de suite pour chaque jeton. Ce mélange d'experts (MoE) ouvert compte 26,4 milliards de paramètres au total, dont 5,4 milliards actifs par jeton, et gère le texte ainsi que les images avec une fenêtre contextuelle d'un million de jetons sous licence Apache 2.0.

Le modèle se positionne en tête des modèles ouverts de moins de 100 milliards de paramètres sur les tests de code agentique, obtenant 48,2 % sur DeepSWE v1.1 et 46,5 % sur Vals Index v2.2. Artificial Analysis lui attribue 20 points sur son Index d'Intelligence, l'égalant avec le Qwen3.8 27B pour un coût environ six fois inférieur et une vitesse quadruplée.

Il s'exécute localement sur les Mac équipés d'au moins 32 Go de mémoire ainsi que sur le matériel Nvidia DGX Spark. Les poids et une version de recherche à boucles variables sont disponibles sur Hugging Face et via le Tinker Playground.

À tester : Télécharger les poids depuis Hugging Face ou tester le modèle dans le Tinker Playground.
